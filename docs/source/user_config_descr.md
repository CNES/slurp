| aux_layers.file_ndwi       | typing.Union[str, NoneType] | NDWI file                                                                                                                                                                |

| stack.malus_shadow         | <class 'int'>               | Value of the malus for pixels in shadow, in the watershed regularization step                                                                                            |
| stack.remove_small_objects | <class 'int'>               | The maximum area, in pixels, of a contiguous object that will be removed                                                                                                 |
| stack.remove_small_holes   | <class 'int'>               | The maximum area, in pixels, of a contiguous hole that will be filled                                                                                                    |
